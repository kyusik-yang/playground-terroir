# Bourgogne Blanc

An interactive guide to 15 white Burgundy villages. Explore the terroir map, browse village profiles, and take the Taste Finder quiz to discover your ideal bottle.

**Live:** [kyusik-yang.github.io/playground-terroir](https://kyusik-yang.github.io/playground-terroir/)

## Features

- Interactive Leaflet map with village markers (color-coded by appellation level)
- Region filter bar (Chablis, Cote de Beaune, Cote Chalonnaise, Maconnais)
- 15 village profile cards with tasting tags, food pairings, producers, and personal notes
- Taste Finder quiz: 4 questions to match you with your top 3 villages
- Fully responsive, single-file HTML (no build tools)

## Tech

- Leaflet.js (CDN) for maps
- Google Fonts (Playfair Display + Inter)
- Vanilla JS, no framework

## Development

Open `docs/index.html` in a browser. That's it.

## Deploy

GitHub Pages serves from the `docs/` folder on the `main` branch.
